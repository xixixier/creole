# 2026-07-07

## Creole-Pages 项目启动

- 用户注册了两个域名：`creole.ccwu.cc`（10年）和 `creole.cc.cd`（1年）
- 决定主域名为 `creole.ccwu.cc`
- 网站方向：不做个人站，做**游戏门户/互动实验场**——网站本身就是内容
- 参考了个网1/2/3的UI风格，融合设计感+创意概念
- 最终风格：纸张纹理 + 衬线字体 + 墨色边框 + 偏移阴影（非像素霓虹）
- 移动端优先：响应式布局，触摸支持

## 游戏站开发

- 已完成8个游戏页面：
  1. **打砖块 (breakout.html)** - 关卡系统，道具系统（多球/扩展/加速/减速），粒子特效，音效
  2. **反应力测试 (reaction.html)** - 反应速度测试，历史记录，PERFECT/GOOD/NORMAL/SLOW/TOO SLOW 评价
  3. **2048 (2048.html)** - 经典数字合并，键盘+触摸滑动支持
  4. **重力弹球 (gravity.html)** - 拖拽扔球物理模拟，可调重力
  5. **像素画板 (pixel.html)** - 8x8像素画工具，16色 palette，镜像对称
  6. **记忆翻牌 (memory.html)** - 4x4配对翻牌，计步数，emoji图案
  7. **贪吃蛇 (snake.html)** - Canvas经典贪吃蛇，键盘+触摸控制，本地最高分
  8. **Simon Says (simon.html)** - 色彩+音调记忆，关卡递增，本地最高关卡
- 入口页面 (index.html) - 游戏选择器，纸张纹理风格，Playfair Display + Inter 字体
- 所有游戏统一布局：返回按钮（fixed top-left, top: 20px）+ 音效开关（fixed top-right）
- 修复 breakout.html 返回按钮位置：从 bottom: 20px 改为 top: 20px，与其他游戏一致
- 清理重复返回链接：每个游戏只保留一个返回按钮，统一文本为"← 返回游戏厅"
- 音效系统：Web Audio API，懒加载（首次点击/触摸初始化），toggleSound() 控制
- snake.html 添加开始覆盖层（overlay），避免页面加载后自动开始游戏
- gravity.html 声音问题修复：原版 playBounceSound 在某些环境下可能因 AudioContext suspended 导致无声
- gravity.html 回滚 bounceCooldowns 逻辑：该逻辑导致球卡住不动且声音密集，已完全移除
- gravity.html 再次修复碰撞音效：添加 BOUNCE_THRESHOLD=1.5，防止球在边界处微弹导致连续"噔噔噔"响
- 待办：部署到 Vercel 并绑定 creole.ccwu.cc 域名
